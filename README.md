# Potok-ETL-w-Pythonie-CSV-i-JSON-
Simple ETL pipeline in Python using Pandas and glob to process CSV and JSON files.

# Potok ETL w Pythonie (CSV i JSON)

Prosty skrypt w Pythonie realizujący podstawowy proces **ETL (Extract, Transform, Load)** na danych klientów zapisanych w plikach CSV oraz JSON.

## Technologie i biblioteki
- Python
- `pandas`
- `glob`

## Pliki w repozytorium
- `courser_etl_2.py` (lub `courser_etl.py`) – główny skrypt realizujący proces ETL
- `klienci_styczen.csv` – przykładowe dane wejściowe w formacie CSV
- `klienci_luty.json` – przykładowe dane wejściowe w formacie JSON
